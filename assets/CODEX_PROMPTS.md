# Codex Image Generation Prompts

Asset creation prompts for "Which Bowl is the Fish In" game.

**Scene Vision:** Three ornate bowls with lids sitting on a mystical temple table. When clicked, lids hinge open to reveal (or not reveal) a fish inside.

---

## Prompt 1: Mystical Temple Background

**Purpose:** Main game background - temple setting with atmospheric lighting

**Prompt:**
```
Create a PNG image (1920x1080px) of a mystical temple interior background. View should be straight-on, showing an ornate back wall with intricate carvings, glowing mystical symbols or runes, warm ambient lighting from unseen sources (torches, magical light). Color palette: deep purples, golds, teals, warm stone colors. Atmospheric with slight haze/god rays. Not too busy - needs to be a backdrop that doesn't distract from gameplay in the center. Art style: slightly whimsical fantasy, detailed but not photorealistic. Think ancient temple meets magical library.
```

**Output:** `assets/background.png`

---

## Prompt 2: Table Surface with Perspective

**Purpose:** Ornate table/altar where the bowls sit, shown in perspective

**Prompt:**
```
Create a PNG image (1920x600px, transparent background) of an ornate wooden table or stone altar surface shown in perspective - wider at the bottom (near viewer), narrower at the top (away from viewer). Should look like it's viewed from slightly above. Rich dark wood with gold inlays, or carved stone with mystical patterns. The surface should have three clear positions where bowls would sit (left, center, right). Warm lighting, casts subtle shadows. Should match the mystical temple aesthetic.
```

**Output:** `assets/table.png`

```
Bowl 1 (Left): Asian-inspired ceramic, blue and white glazing, dragon or koi fish patterns on exterior
Bowl 2 (Center): Middle Eastern brass or gold metal, geometric patterns, jeweled accents
Bowl 3 (Right): Stone or carved jade, nature motifs (vines, leaves), slightly weathered

All match mystical temple aesthetic. Empty interiors visible from this angle.
```

- `assets/bowls/bowl_base_left.png`
- `assets/bowls/bowl_base_center.png`
- `assets/bowls/bowl_base_right.png`

## Notes:

- All images should have **transparent backgrounds** (PNG with alpha channel) except the main temple background
- **512x512px** for bowls, lids, and fish (will be scaled down in-game)
- **Consistent art style** across all assets - mystical temple theme
- **Clean edges** for proper alpha blending
- Save fish images with the naming convention: `{fish_id}.png` matching the IDs in `fish_library.toml`
- Bowl bases and lids are separate assets to allow smooth hinge animation

## Asset Animation Notes:

**Bowl Opening Animation:**
- Bowl bases remain stationary
- Lids rotate/hinge open (we'll animate rotation in code)
- Hinge point should be clearly on one edge of the lid
- Smooth animation speed controlled in code

**Fish Reveal:**
- Fish emerges from bowl center
- Animates to center screen with scale/fade
- Fact displays with fish image

## Priority Order:

1. **Temple Background** (Prompt 1) - Sets the scene
2. **Table Surface** (Prompt 2) - Bowls need somewhere to sit
3. **Bowl Bases & Lids** (Prompts 3-4) - Core gameplay, needed for bowl opening
4. **Fish Batch 1** (Prompt 5) - Core gameplay content
5. **Fantastical Fish Batch 1** (Prompt 7) - Adds magical variety
6. **Success Particles** (Prompt 9) - Polish/feedback
7. **UI Elements** (Prompt 10) - For journal/menus
8. Everything else - Nice to have

You can generate these in batches as time allows! Start with background and bowls to get the mystical temple look working.
