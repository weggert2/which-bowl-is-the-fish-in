# Which Bowl is the Fish In?

This game is written in Rust. It's the most performant, memory-safe fish guessing game you'll ever see in your life.

## What is this?

Click on bowls. There are over 120 fish to find and learn about. Become a fish expert. Refuse to use javascript ever again.

## Running

```bash
cargo run
```

## Windows release package

From PowerShell, run `./scripts/package-release.ps1`. It builds the release executable, stages it with its required `assets` folder, and creates `dist/which-bowl-win64.zip`. Unzip that archive and run `which-bowl.exe` with the included `assets` folder beside it.
