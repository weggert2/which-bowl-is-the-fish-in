# Which Bowl is the Fish In?

This game is written in Rust. It's the most performant, memory-safe fish guessing game you'll ever see in your life.

## What is this?

Click on bowls. Find fish. That's it. We're using a systems programming language for this.

## Running

```bash
cargo run
```

You'll need Rust installed. Because of course you will.
